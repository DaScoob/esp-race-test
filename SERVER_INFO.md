# SERVER_INFO — esp-race-test

Factual status of the ESP Race test environment. Everything listed here was verified on the local machine; unknown or unverified items are marked as such.

## Architecture (verified)

```
ESP32 devices (planned, not connected)   →  FastAPI backend (docker container "race-api")
Browser test interface (static, /ui)      ↗   SQLite (bind mount ./data → /app/data/race.db)
Artifacts (/downloads, read-only bind)    ↗   uvicorn inside container, non-root uid 1000
```

- Backend: FastAPI + uvicorn, Python 3.13-slim container (`Server/Dockerfile`).
- Database: SQLite WAL, host volume `BierPeter/Server/data/race.db`, created empty on first start; no seeds/demo data. Schema is initialized at container startup.
- Test interface: static files from `Interface/`, bind-mounted read-only to `/app/ui` and served same-origin at `/ui/` by the same FastAPI app. Same-origin means no CORS is needed locally.
- Firmware source: `Firmware/esp-race-test/`, written for Arduino-ESP32 Core 3.x. PlatformIO and physical board build/flash tests are pending.
- Artifacts: `artifacts/` bind-mounted read-only to `/app/downloads` and served at `/downloads/`:
  - `GET /downloads/` → HTTP 200 index page (generated by `Server/scripts/artifacts_index.py`, read-only bind) listing every ZIP with size, creation date, and SHA-256 prefix.
  - `GET /downloads/<filename>.zip` → direct download. Serving is restricted to that dedicated artifact directory; nothing else of the host filesystem is exposed.

## API origin and routes (verified against the running container, HTTP 200/201/401/403/404/409/422)

Base (local): `http://192.168.178.60:6017` (same values on `127.0.0.1:6017`)

- `GET /api/v1/health` — no auth
- Device endpoints (header `X-Device-Key`): `POST /api/v1/heartbeat`, `POST /api/v1/events`, `GET /api/v1/commands?device_id=MAC`, `POST /api/v1/commands/ack`
- Admin endpoints (header `X-Admin-Key`): `GET /api/v1/devices`, `GET /api/v1/events`, `GET /api/v1/pairings`, `POST /api/v1/pairings`, `POST /api/v1/unpair/{device_id}`
- `GET /ui/` and `/ui/app.js`, `/ui/ui-logic.js`, `/ui/style.css` — test interface, no auth (it obtains the admin key at runtime from the user)
- `GET /downloads/` — artifact directory index (read-only bind, dedicated directory only; no host filesystem, secrets, databases, logs, or runtime data reachable)
- OpenAPI: `/docs`, `/openapi.json`

Response schemas and timestamp format (ISO 8601 UTC, microseconds, `Z`) are fully documented in `Server/README.md` and live at `/openapi.json`.
